## Quick facts

- **Repo:** `patterncatalyst/enterprise-integration-patterns-with-camel`
- **Purpose:** A comprehensive guide to the **Enterprise Integration Patterns** implemented with Apache Camel on three runtimes (Quarkus, Spring Boot, and YAML DSL)
- **Build:** `mvn verify` (runs all tests)
- **Fast Build:** `mvn verify -DskipTests` (skips all tests)
- **CI:** GitHub Actions on every push/PR to `main`
- **Key versions:** Java 25 · Apache Camel 4.20.0 · Quarkus 3.37.0 · Citrus 5.0.0
- **Runtimes in use:** Quarkus, Spring Boot, YAML DSL
